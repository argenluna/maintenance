## 2026-11-25 (2차) — 홀씨 국소 밴드 튐 (전역 EQ로 안 잡히는 경우)

### 문제
전역 7밴드 EQ(`supplement_effect.py`)는 곡 전체 평균만 맞춘다.
홀씨 02:24~02:44 에서 1초 프레임 기준 **145~156초 200~500Hz +3~6.6dB**,
140~142초 4~8k +4.2dB 가 남았다. 1차/2차 검증은 곡 평균이라 통과했음.

### 오진 정정
처음 "153.4~154.4초 voice_0 삽입음"이라고 보고했는데 재측정 결과
voice_0/voice_1 은 그 구간에서 원본·변환 모두 RMS 0.00005~0.00018 로
사실상 무음이었다. `librosa.yin` 이 무음 노이즈에 가짜 f0(724Hz)를
반환한 것을 삽입음으로 오해한 것. **무음 구간 f0 판정은 RMS 게이트를 먼저.**
실제 이상은 밴드 밸런스였음.

### 구현 (`local_band_fix.py`)
- 1초 창 / 0.25초 hop 으로 원곡 대비 밴드 비율(dB) 계산
-deadband 1dB, cap ±2dB, 0.4초 평활 → 시간 변화 게인
- butter 4차 밴드패스 7개로 분해 후 게인 곱해 합산
- 전부 **원곡 대비 상대값**, 절대 임계 없음

## 2026-11-25 (1차) — 스킬 신설 / eight 검증

### 사용자 정의한 흐름
> "supplement effect는 unmix 후 effect에서 누락되거나 적용 안 된 게 있으면
> verification effect에서 검증한 후 목록을 남겨뒀다가 mix 후에
> supplement effect로 적용하는 거야. 그리고 verification effect를 한 번 더 돌리고."

```
unmix → RVC → effect → mix
  → effect-verification 1차 (검출 + 보충 목록)
  → supplement-effect (목록 중 post_mix만)
  → effect-verification 2차
  → safety gate → 마스터링
```

### 분류 (fx_verify.build_supplement_plan)
- `post_mix` — 밴드 EQ / 스테레오 폭 / 보컬대역 / 잔향 꼬리.
  풀믹스에서만 측정·보충 가능 → supplement-effect가 처리.
- `pre_mix` — tone/tail/env/onset/pan 강도.
  **assemble.py의 기존 피드백(max_rounds=2, 배율 0.4~2.2 클립)이 이미 처리.**
  새 회귀 루프를 만들지 않고 분류·기록만 한다.
- `no_action` — gate/echo/pitch(의도적 off), 기록만.

### 사용자 질문: "답안지(원곡)가 있으면 맞추기만 하면 되는 거 아냐?"
→ 맞다. 복잡한 axis 임계 룰을 **원곡 대비 거리 하나**로 대체했다.

`supplement_guard.py::distance(rep)` — 8개 항목을 0~1로 정규화해 평균:
`band`, `hf`, `stereo`(원곡 lr_corr와의 차), `vocal_band`, `bury`,
`tail`, `env_mod`, `env_corr` — 전부 `원곡=1.0` 기준 상대값.

판정: `distance_after < distance_before - tol(0.005)` 이면 채택, 아니면 롤백.
하드 거부는 거리가 못 보는 것만: NaN 증가, 피크 클립, 딸깍 급증(원곡 대비 +30% 초과).

⚠️ **crest / raw clicks 절대값은 쓰지 않는다.** 고역 게인에 비례해 늘어나
오탐이 된다(기존 `dynamic_ratio` 오탐과 같은 계열). eight 실측에서
clicks 34272 → 36199(+5.6%)는 고역 +2dB의 자연 결과였고, 1.30배 룰로 통과.
