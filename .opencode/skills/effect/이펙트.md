### 버그 및 수정
1. `def _ convolver` (공백) → `_convolver`. `butter(bandpass)` 단일 Wn → `[f/√2, f*√2]`.
2. `np.arange(n, np.float32)`가 stop 인자로 해석 → `dtype=` 수정 (44개 이펙트 동시 실패).
3. `A.gate_from()` 튜플 반환을 그대로 쓰면 2D 배열 → `[0]`. `A.match_tone()`도 튜플 → `[0]`.
4. yIN 배음 오탐 761Hz → pyin + 힌트 ±7반음 (이전 언믹싱 12차 교훈 재확인).
5. yIN 하드 게이트 잔차 마스크가 전부 0 → 꼬리 추출 방식 변경 (아래 메모리 항목).
6. 단일 441ms 에코 탭은 박자 오탐 → 4구간 일관성 + 2탭 이상 배수 간격 요구.

### 💾 메모리 (중요)
- **65.5GiB 스파이크 원인**: `librosa.effects.pitch_shift(194초 전체)`가
  `(8578333, 1025, 1) complex64`를 한 번에 할당. → `effects.pitch_to`가 **8초 청크 + 50ms 크로스페이드**로 수정.
- 전곡 `A.match_tone` (float64 850만 × 7밴드 × 4회) → `_tone_match_chunked`
  (20초에서 게인 계산, 10초 청크 적용).
- 전곡 `P.dereverb` STFT(수백 MB) 제거 → 노래 끝 직후 빈 구간의 **원본 파형**만 최대 12초.
